# 顧客登録処理フロー (flow.md)

## 顧客登録時の処理手順

1. 利用者が顧客登録画面で情報を入力  
   - 名前、住所、電話番号、メールアドレス

2. 入力値のバリデーション  
   - 必須項目チェック  
   - フォーマットチェック（電話番号、メール）

3. 暗号化処理  
   - AES-256-CBCで顧客情報を暗号化  
   - 共通鍵はアプリケーション環境変数から取得

4. CSVファイルへの保存  
   - `customers.csv` に追記  
   - 顧客IDは自動採番

5. ログ記録  
   - `logs.csv` に操作ログを保存  
   - 記録内容：利用者ID、操作種別（登録）、顧客ID、日時

6. 完了通知  
   - 「登録が完了しました」と画面に表示
