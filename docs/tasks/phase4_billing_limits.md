# Task: Phase 4 - 課金・制限機能 (Billing & Limits)

## 概要
多様な課金モデルに対応したロジックと、プランに基づく機能制限を実装する。

## 目的
- 収益化モデルの実現
- 契約プランに応じた適切な利用制限の適用

## 作業内容

### 1. 課金ロジック実装
- [ ] **プラン定義**
    - [ ] Basic, Standard, Premium, 従量, トランザクション, ハイブリッドの各パラメータ定義
- [ ] **制限チェックロジック**
    - [ ] 顧客登録数上限チェック
    - [ ] 検索回数上限チェック (Redis等は使わず、ログまたはメモリ/ファイルで簡易管理)

### 2. ミドルウェア/デコレータ実装
- [ ] **制限適用**
    - [ ] 顧客登録・検索アクション実行前にプラン制限を確認する処理
    - [ ] 制限超過時のエラーハンドリング

### 3. 請求管理機能
- [ ] **課金計算**
    - [ ] 操作ログ (`logs.csv`) に基づく従量・トランザクション料金の計算
- [ ] **請求データ保存**
    - [ ] `billing.csv` への請求情報記録 (暗号化)

## 完了条件
- プランごとの登録上限数で登録がブロックされること。
- 操作ログに基づいて正しい課金額が計算されること。
