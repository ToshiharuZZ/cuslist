# Task: Phase 3 - 顧客管理機能 (Customer Management)

## 概要
システムのコア機能である顧客リストの登録・検索・編集・削除 (CRUD) 機能を実装する。

## 目的
- 顧客情報の安全な管理と活用
- 暗号化された状態での検索機能の実現

## 作業内容

### 1. 顧客モデル実装
- [ ] **Customerクラス**
    - [ ] `customers.csv` とのマッピング
    - [ ] 属性 (ID, 名前, 住所, 電話, Email) の定義
    - [ ] 自動採番ロジック

### 2. CRUD機能実装
- [ ] **新規登録**
    - [ ] 入力フォーム作成
    - [ ] バリデーション (必須チェック, 形式チェック)
    - [ ] 全項目の暗号化と保存
- [ ] **一覧表示**
    - [ ] CSV読み込みと復号処理
    - [ ] 画面への表示
- [ ] **編集機能**
    - [ ] 既存データの表示
    - [ ] 更新データの再暗号化と保存
- [ ] **削除機能**
    - [ ] 指定IDのレコード削除 (または論理削除)

### 3. 検索機能実装
- [ ] **メモリ内検索**
    - [ ] 全件読み込み・復号後のフィルタリング処理実装
    - [ ] 名前、電話番号等での検索

## 完了条件
- 顧客の登録・表示・編集・削除が正常に行えること。
- 保存されたCSVファイルの中身が暗号化されていること。
- 検索機能が正しく動作すること。
