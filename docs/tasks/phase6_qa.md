# Task: Phase 6 - テスト・品質保証 (QA)

## 概要
システム全体の動作確認、負荷テスト、セキュリティチェックを行い、リリースの品質を保証する。

## 目的
- バグの検出と修正
- パフォーマンス要件とセキュリティ要件の適合確認

## 作業内容

### 1. 結合テスト
- [ ] **シナリオテスト**
    - [ ] 管理者によるユーザー作成 -> ユーザーログイン -> 顧客登録 -> ログアウト
    - [ ] 課金プラン制限の境界値テスト (上限-1, 上限, 上限+1)
    - [ ] 課金計算の正確性確認

### 2. 負荷テスト
- [ ] **データ量検証**
    - [ ] 顧客データ1000件〜数千件程度での検索レスポンス確認
    - [ ] 必要に応じてインデックス化や分割保存の検討 (今回は検証のみで可とする場合もあり)

### 3. セキュリティチェック
- [ ] **暗号化確認**
    - [ ] CSVファイルを直接開き、個人情報が平文で見えないことを確認
- [ ] **アクセス制御確認**
    - [ ] URL直打ちによる未認証アクセスのブロック確認
    - [ ] 他のユーザーのデータへのアクセス可否 (マルチテナント的な要件があれば)

## 完了条件
- 重大なバグが存在しないこと。
- セキュリティ要件 (暗号化) が満たされていること。
- パフォーマンスが許容範囲内であること。
