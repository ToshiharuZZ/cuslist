# Task: Phase 2 - 利用者管理機能 (User Management)

## 概要
管理者による利用者管理機能と、セキュアな認証機能を実装する。

## 目的
- システム利用者の認証とアクセス制御の実現
- 管理者によるユーザー管理フローの確立

## 作業内容

### 1. 利用者モデル実装
- [ ] **Userクラス**
    - [ ] `users.csv` とのマッピング
    - [ ] ユーザー属性 (ID, パスワードハッシュ, 権限, プラン等) の定義
- [ ] **データアクセス**
    - [ ] IDによるユーザー検索
    - [ ] 新規ユーザーの追加

### 2. 認証機能実装
- [ ] **ログイン処理**
    - [ ] ID/パスワード検証 (ハッシュ照合)
    - [ ] セッション管理 (Flask-Login等の利用検討)
- [ ] **ログアウト処理**
    - [ ] セッション破棄
- [ ] **アクセス制御**
    - [ ] 未認証ユーザーのリダイレクト処理

### 3. 利用者管理画面 (管理者用)
- [ ] **利用者一覧画面**
- [ ] **利用者登録機能**
    - [ ] ID, パスワード, 権限, プランの入力
    - [ ] パスワードのハッシュ化保存
- [ ] **利用者削除機能**

## 完了条件
- 管理者でログインし、利用者の追加・削除ができること。
- 一般利用者でログインできること。
- 未認証状態で保護されたページにアクセスできないこと。
