# 顧客リスト管理システム 詳細設計 (detail.md)

## 1. CSVフォーマット仕様

### 🔐 利用者情報CSV (`users.csv`)
- 保存内容はすべて暗号化（パスワードはハッシュ化）
- カラム構成：

| カラム名       | 内容                          | 備考 |
|----------------|-------------------------------|------|
| user_id        | 利用者ID（ユニーク）          | 平文保存可（検索キー） |
| password_hash  | パスワードハッシュ             | SHA-256等 |
| role           | 権限（admin / user）          | 平文保存可 |
| created_at     | 登録日時                      | ISO8601形式 |

---

### 👥 顧客情報CSV (`customers.csv`)
- 顧客情報は暗号化して保存
- カラム構成：

| カラム名       | 内容                          | 備考 |
|----------------|-------------------------------|------|
| customer_id    | 顧客ID（ユニーク）            | 平文保存可（検索キー） |
| name_enc       | 顧客名（暗号化）              | AES暗号化 |
| address_enc    | 住所（暗号化）                | AES暗号化 |
| phone_enc      | 電話番号（暗号化）            | AES暗号化 |
| email_enc      | メールアドレス（暗号化）      | AES暗号化 |
| created_at     | 登録日時                      | ISO8601形式 |

---

## 2. 暗号化方式

### 利用者情報
- **パスワード**：ハッシュ化（SHA-256 + ソルト）
- **その他属性**：平文保存（検索性確保のため）

### 顧客情報
- **暗号化方式**：AES-256-CBC（共通鍵暗号）
- **鍵管理**：アプリケーション側で安全に保持（環境変数や設定ファイルに格納）
- **復号処理**：認証済み利用者のみアクセス可能

## 4. 運用上の考慮点
CSVファイル分割：顧客件数が増えた場合、年度ごとや顧客ID範囲ごとに分割保存
ログ管理：操作ログ（利用者ID、操作種別、対象顧客ID、日時）を別CSVで保存
バックアップ：定期的に暗号化したCSVをバックアップ
