## 1. はじめに
本システムは、顧客情報を高度な暗号化技術を用いて安全に管理し、実写データセットに基づく高精度（85%以上）な属性解析を提供するエンタープライズ向け管理システムです。データは最新のデータベース（SQLAlchemy/SQLite）に格納され、高い検索性能と整合性を確保しています。

## 2. ログインとセキュリティ
### 2.1 ログイン方法
1. `http://localhost:5000` にアクセスし、IDとパスワードを入力します。
2. 5回連続で間違えるとセキュリティロックがかかります。

### 2.2 データの安全性
- **透過的暗号化**: 顧客名、住所、連絡先、解析結果、およびユーザー残高は、保存時に自動的に暗号化されます。
- **パスワード保護**: パスワードは最新のハッシュ化アルゴリズムにより、システム管理者でも復元不可能な状態で保存されます。

## 3. ダッシュボード
ログイン後、以下の主要セクションにアクセス可能です。
- **顧客管理**: 登録・検索・AI解析結果の確認。
- **プラン管理**: 課金状況の確認とプラン変更。
- **ログ表示**: 自身の過去の操作履歴の確認。

## 4. 顧客管理とAI解析
### 4.1 顧客検索
- **高速検索**: DBインデックス最適化により、大量のデータから瞬時に検索が可能です。
- **AI解析結果**: 顧客詳細画面にて、AIが実写データから解析した属性情報（精度85%以上）を確認できます。

### 4.2 登録・編集・削除
- 顧客データの操作内容はすべて「操作ログ」として記録され、監査に利用可能です。

## 5. 契約プランと変更・解約
### 5.1 プラン変更 (Plan Change)
- プランのアップグレード/ダウングレードが可能です。
- **日割り計算**: 月の途中で変更した場合、旧プランの使用日数に応じた日割り計算が適用されます。

### 5.2 アカウント解約 (Cancellation)
- 解約手続き後、アカウントは即座にログイン不可となります。
- **データ保持期間**: 解約後 **30日間** はデータが保護されます。この期間内であれば、管理者に依頼してアカウントを再有効化することが可能です。
- 30日を過ぎると、すべての顧客データとユーザー情報は物理的に削除され、復旧できなくなります。

## 6. 管理者向け機能
管理者は CLI (Command Line Interface) を通じて以下のメンテナンスが可能です。

- **期限切れアカウントの削除**:
  ```bash
  flask cleanup-accounts
  ```
  このコマンドを実行することで、保持期間（30日）を過ぎた解約済みユーザーのデータを安全に一括削除します。

## 7. トラブルシューティング
- **ログインロック**: 管理者にお問い合わせください。
- **解析精度の不足**: 解析対象の写真の品質を確認してください。本システムは高品質な実写データで85%以上の精度を保証しています。
- **データの不整合**: システムが SQLAlchemy ベースへ移行したため、手動でのCSV書き換えなどは無効となりました。必ずWebまたはCLI上から操作してください。
